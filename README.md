# polymarket-ladder

Detector de arbitragem de escada em mercados de temperatura da Polymarket.

Ver [CLAUDE.md](CLAUDE.md) para contexto completo do projeto, decisões de
escopo e o levantamento de endpoints de API usados.

**Fase atual**: apenas estrutura de projeto. Sem lógica de coleta ou detecção
implementada ainda, e sem execução de ordens em nenhuma fase planejada até
segunda ordem.

## Instalação (desenvolvimento)

pip install -e ".[dev]"
